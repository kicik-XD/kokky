# kokky

Музыкальный плеер в тёмном минималистичном стиле — HTML, CSS и ванильный JS.
Интерфейс повторяет референс, но под брендом **kokky**.

## Что внутри

- **Живая лента Audius** без вшитых подборок и статического списка треков: при запуске
  загружаются актуальные тренды, а поиск идёт по всему каталогу.
- Раздел **«Плейлисты»**: квадратная кнопка **«создать плейлист»**, свои плейлисты
  сохраняются в `localStorage`.
- После создания плейлист открывается: внутри можно добавлять треки через поиск Audius,
  убирать их и запускать весь список.
- На «Моём потоке» кнопка **«Добавить в плейлист»** рядом с перемоткой — выбираете,
  в какой из своих плейлистов положить текущий трек. То же действие есть в меню `⋯`.
- Источник — **Audius**: легальные полные треки, публичный API, без аккаунта, OAuth и токенов.
- Обложки берутся прямо из Audius по публичным ссылкам, ничего не скачивается и не токенизируется.
- Поиск работает в два слоя: мгновенно по загруженной ленте и через живой поиск Audius
  по всему каталогу (с задержкой 260 мс и защитой от гонок).
- Полноценное воспроизведение: перемотка, пауза, следующий/предыдущий трек, автопереход,
  громкость, лайки с сохранением в `localStorage`.
- Горячие клавиши: `Space` — пауза, `←/→` — ±5 сек, `↑/↓` — громкость, `/` — поиск.
- Адаптивная мобильная версия с нижней навигацией.
- Логотип и кнопка play — обычные треугольники.

## Запуск

Просто откройте `index.html` в браузере — сборка не нужна. Для аудио, обложек и живого
поиска нужен интернет.

Если браузер ограничивает `file://` или не отдаёт аудио из-за политики источника,
запустите локальный сервер:

```powershell
cd C:\Users\Admin\kokky
python -m http.server 8000
```

и откройте `http://localhost:8000`.

## Как устроен звук

- Поток: `https://api.audius.co/v1/tracks/{id}/stream?app_name=KOKKY` — отдаёт полный
  аудиофайл с поддержкой range-запросов, поэтому перемотка работает.
- Используется именно endpoint по ID, а не подписанная ссылка `stream.url`: она истекает.
- Лента: `https://api.audius.co/v1/tracks/trending?app_name=KOKKY` — живые тренды без
  встроенного снимка каталога.
- Живой поиск: `https://api.audius.co/v1/tracks/search?query=...&app_name=KOKKY`.
- Если сеть недоступна, плеер сообщает об этом; встроенных треков-заглушек нет.

## Файлы

- `index.html` — разметка и SVG-иконки
- `styles.css` — дизайн, адаптив, анимации
- `app.js` — плеер, живая лента, поиск, плейлисты, лайки, меню, клавиатура
- `library.js` — настройки источника Audius
- `assets/` — локальный аватар профиля
