# kokky

Музыкальный плеер в тёмном минималистичном стиле — HTML, CSS и ванильный JS.
Интерфейс повторяет референс, но под брендом **kokky**.

## Что внутри

- **Живая лента YouTube** без вшитых подборок и статического списка треков: при запуске
  собираются актуальные песни по нескольким жанровым запросам, а поиск идёт по всему
  каталогу YouTube.
- Раздел **«Плейлисты»**: квадратная кнопка **«создать плейлист»**, свои плейлисты
  сохраняются в `localStorage`.
- После создания плейлист открывается: внутри можно добавлять треки через поиск YouTube,
  убирать их и запускать весь список.
- На «Моём потоке» кнопка **«Добавить в плейлист»** рядом с перемоткой — выбираете,
  в какой из своих плейлистов положить текущий трек. То же действие есть в меню `⋯`.
- Источник — **YouTube**: полные треки, огромный каталог, без аккаунта, OAuth и токенов.
- Воспроизведение идёт через **официальный YouTube IFrame Player API** — это легальный
  способ встраивания. Плеер виден в квадрате обложки, поэтому реклама и брендинг YouTube
  остаются на месте.
- Поиск работает в два слоя: мгновенно по загруженной ленте и через живой поиск YouTube
  по всему каталогу (с задержкой 260 мс и защитой от гонок).
- Полноценное управление: перемотка, пауза, следующий/предыдущий трек, автопереход,
  громкость, лайки и плейлисты с сохранением в `localStorage`.
- Горячие клавиши: `Space` — пауза, `←/→` — ±5 сек, `↑/↓` — громкость, `/` — поиск.
- Адаптивная мобильная версия с нижней навигацией.
- Логотип и кнопка play — обычные треугольники.

## Запуск

Самый простой способ — **дважды кликнуть `start.bat`** в папке `kokky`. Скрипт поднимет
локальный сервер и откроет `http://localhost:8000` в браузере.

Можно и вручную:

```powershell
cd C:\Users\Admin\kokky
python -m http.server 8000
```

и открыть `http://localhost:8000`.

Открывать `index.html` двойным кликом (`file://`) нельзя: YouTube запрещает встраивать
плеер на страницах `file://`, поэтому на обложке появляется «Ошибка конфигурации».
Приложение само показывает подсказку и кнопку **«Как запустить»**.


## Как устроен звук

- Воспроизведение: **YouTube IFrame Player API** (`https://www.youtube.com/iframe_api`).
  Плеер создаётся в блоке `#ytPlayer` внутри обложки и управляется через
  `loadVideoById`, `cueVideoById`, `playVideo`, `pauseVideo`, `seekTo`, `setVolume`.
- Поиск: публичные **Piped**-инстансы (`/search?filter=music_songs`) — без ключей и
  регистрации. Используется первый доступный из списка `piped` в `library.js`.
- Лента собирается из нескольких жанровых запросов (`feedQueries` в `library.js`),
  перемешивается и кэшируется на несколько часов в `localStorage` (`kokky:feed:yt`),
  чтобы плеер сразу открывался с треками даже при медленной сети.
- Обложки — публичные превью `https://i.ytimg.com/vi/{id}/hqdefault.jpg`.
- Необязательный апгрейд: если указать ключ **YouTube Data API v3** в
  `library.youtube.apiKey`, поиск пойдёт через официальный API Google вместо Piped.
  Ключ не обязателен.

## Ограничения YouTube

- Реклама перед/во время трека — часть официального плеера, её нельзя убрать.
- Некоторые видео запрещают встраивание (`embeddable: false`) — плеер сообщает об этом
  и автоматически переключает на следующий трек.
- На мобильных браузерах автозапуск со звуком заблокирован: первый трек запускается
  нажатием **play**, дальше автопереход работает.
- Публичные Piped-инстансы иногда недоступны. Приложение перебирает список и сообщает,
  если поиск не удался; лента при этом берётся из кэша.

## Файлы

- `index.html` — разметка, SVG-иконки и контейнер YouTube-плеера
- `styles.css` — дизайн, адаптив, анимации
- `app.js` — плеер, лента, поиск, плейлисты, лайки, меню, клавиатура
- `library.js` — источник, Piped-инстансы, жанровые запросы и необязательный API-ключ
- `start.bat` — запуск локального сервера и открытие плеера в браузере
- `assets/` — локальный аватар профиля
